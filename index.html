常見問題

可以查詢貨物實時位置嗎？

可以。每張訂單均有專屬追蹤編號，客戶可登入系統 jpholdingshk.com 或經電郵 contact@jpholdingshk.com 查詢貨物實時狀態、預計到達時間及溫度紀錄（如適用）。

服務合約設有最低用量嗎？

不設最低用量。我們的計費方式靈活，可按件、按板、按月費任君選擇，適合不同規模的企業從試點開始合作。

系統能與我們現有 ERP 對接嗎？

我們的平台支援標準 API 及 EDI 對接，已與 SAP、Oracle 及多個主流 ERP 系統完成實戰整合，對接周期一般只需 2-4 週。

提供冷鏈或特殊貨品服務嗎？

提供。我們設有恆溫及冷凍倉庫，並具備危險品及高價值貨品專案管理經驗，歡迎致電 78298865 與我們的方案顧問詳談。
